# Gacha Calendar 0.1.0

追踪抽卡游戏卡池、活动与版本公告的桌面日历。

A desktop calendar for gacha banners, events and updates.

- 多游戏与多区服公告聚合、时间线和列表视图、筛选与搜索。
- 收藏、完成和隐藏标记、自定义来源、自动刷新、ICS 导出。
- Multi-game and multi-region announcements, timeline/list views, filters and search.
- Star/complete/hide entries, custom sources, automatic refresh and ICS export.

Windows x64：下载 `Setup.exe` 安装，或解压 `portable.zip` 运行；均包含 .NET 运行时。

Windows x64: use the setup executable or extract the portable ZIP. Both include the .NET runtime.

发布包从干净的构建输出生成，不包含已有 dist/、个人设置、缓存或调试符号。可使用 SHA256SUMS.txt 校验下载内容。

Packages use clean build output and exclude existing dist/ contents, personal settings, caches and debug symbols. Verify downloads with SHA256SUMS.txt.
